# Terraform - AWS infrastructure for the Architecture Planner

Creates (region eu-central-1 by default): VPC, EKS 1.35, two managed node groups, add-ons (vpc-cni, kube-proxy,
coredns, EBS CSI), OIDC + IRSA roles, Karpenter (roles, SQS, EventBridge), ECR, S3 backup bucket (lifecycle 30/60/90),
Secrets Manager secrets (random passwords), optional Route53 zone.

## Use
```bash
aws configure                      # or aws sso login
cd terraform
terraform init
terraform validate
terraform plan                     # read it!  ~90 resources
terraform apply                    # ~15-20 minutes (EKS control plane is the slow part)
$(terraform output -raw configure_kubectl)
cd .. && python3 scripts/update-helmfile-env.py     # fills environments/default.yaml
./scripts/push-images.sh v1.0.0                     # build + push images to ECR
```

## Remove everything (important order)
```bash
./scripts/pre-destroy.sh     # removes ALB, Karpenter nodes, EBS volumes first
cd terraform && terraform destroy
```

## Notes
* Never validated against the real AWS provider by the author: run `terraform validate` and `terraform plan` first.
* Secrets (DB password, JWT) are generated by Terraform and therefore stored in `terraform.tfstate`. Keep it private.
* Single NAT gateway (cheaper, not highly available). DB node group lives in ONE AZ because EBS disks are AZ-bound.
* ECR repo names are `<cluster_name>/frontend|backend`; `values/*.gotmpl` hard-code `arch-planner/...`, so keep the default cluster name or change them.
